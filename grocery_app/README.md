# 🏪 نظام إدارة محل البقالة

## 📱 عن البرنامج
تطبيق Flutter كامل لإدارة محل البقالة يعمل على أندرويد بالكامل بدون إنترنت.

---

## ✅ المميزات الكاملة

### 🛒 نقطة البيع (الكاشير)
- بحث سريع عن المنتجات بالاسم
- **مسح الباركود / QR Code بكاميرا الهاتف** (بدون أجهزة خارجية)
- إضافة/حذف منتجات من السلة
- تعديل الكميات
- تطبيق خصم
- طرق دفع متعددة: كاش / أجل / فودافون كاش / انستاباي
- تسجيل الفواتير فورياً وتحديث المخزون تلقائياً

### 📦 إدارة المخزون
- إضافة / تعديل / حذف المنتجات
- **مسح الباركود من الكاميرا عند إضافة منتج**
- تصنيف المنتجات (مشروبات، أغذية، منظفات، إلخ)
- تحديد وحدات (قطعة، كيلو، لتر، إلخ)
- تحديد **حد أدنى للتنبيه** عند نفاد المخزون
- **تنبيه تلقائي** عند وصول أي منتج للحد الأدنى

### 🚚 المشتريات من الموردين
- تسجيل فواتير الشراء من الموردين
- تحديث المخزون تلقائياً عند الشراء
- تتبع المدفوع والمتبقي (الديون)

### 👥 إدارة الموردين
- إضافة بيانات الموردين (اسم، هاتف، عنوان)
- تتبع ديون كل مورد
- سداد الديون وتحديث الرصيد

### 💸 المصروفات
- تسجيل مصروفات المحل (إيجار، فواتير، مرتبات، إلخ)
- تصفية حسب الفترة الزمنية

### 📊 التقارير المالية
- **تقرير يومي**: مبيعات، أرباح، مصروفات، صافي ربح
- **تقرير شهري**: تفصيلي بكل العمليات
- **أفضل المنتجات مبيعاً** في الشهر

### 🔒 الأمان
- حماية بـ **رقم سري مكون من 4 أرقام**
- شاشة قفل احترافية عند فتح التطبيق

### ⚙️ الإعدادات
- تغيير اسم المحل
- تغيير العملة (جنيه، دولار، يورو، ريال، إلخ)
- تشغيل/إيقاف تنبيهات المخزون
- تغيير الرقم السري

## 🏗️ طريقة البناء (Build)

### المتطلبات:
- Flutter SDK 3.0+
- Android Studio / VS Code
- Android SDK (API 21+)

### خطوات البناء:

```bash
# 1. فتح المجلد
cd grocery_store_manager

# 2. تنزيل المكتبات
flutter pub get

# 3. بناء APK
flutter build apk --release

# 4. ستجد الـ APK هنا:
# build/app/outputs/flutter-apk/app-release.apk
```

### لتنزيل الـ APK مباشرة على الهاتف:
```bash
flutter run --release
```

## 📦 المكتبات المستخدمة

| المكتبة | الغرض |
|---------|-------|
| `sqflite` | قاعدة بيانات SQLite محلية |
| `mobile_scanner` | مسح الباركود بالكاميرا |
| `intl` | تنسيق التواريخ بالعربي |
| `path_provider` | الوصول لمجلدات الهاتف |
| `share_plus` | مشاركة الملفات |
| `pdf` | إنشاء PDF |
| `printing` | طباعة الفواتير |

## 🛡️ خصائص تقنية
- **أوفلاين بالكامل** - يعمل بدون إنترنت
- **قاعدة بيانات محلية** - البيانات محفوظة على الهاتف
- **سريع جداً** - SQLite مع Transactions لضمان السرعة
- **يدعم العربية** بالكامل مع RTL
- **Android API 21+** (أندرويد 5.0 فأعلى)
